# 石之迷宫 · THE STONE LABYRINTH

**Three.js 正交视角 × 可玩的 3D 像素微缩石迷宫**，纯白背景，低多边形石材、苔藓、古树、三重封印。无电影截图、材质包、模型或第三方图片；所有三维场景均由代码生成。作为黑暗童话与石质遗迹题材的原创互动练习，不是电影官方游戏。

## Chapter 01 · 遗忘之井

这次针对用户提供的《潘神的迷宫》电影剧照，重建两处最重要的外形识别点：

- **入口石拱门**：建筑坐落在环形迷宫朝向镜头的入口，13 块扇形楔石构成完整拱券，双侧砌石门柱，正面有石刻面孔、深凹眼窝、牙齿；下方是可以通行的洞口，附近有树根和残墙。
- **真正向下延伸的中央圆井**：井口半径 3.55 世界单位，外侧环形石沿分成 42 块有接缝的石块；井壁是**上窄下阔**的空心石质漏斗，深度 4.9 世界单位，并有环形石层及砖缝。
- **52 级三维螺旋石阶**：独立的扇形实体石阶，从井沿向内盘旋超过两圈，一级一级下降到井底。井口北侧留有衔接台阶的缺口；小型立石被放在底部，而不是遮住井口。
- **角色真正沿石阶下降**：游戏仍以 19×19 逻辑网格保证路径和机关稳定，但最后十个网格节点映射到实际三维螺旋线；行走插值走曲线，不会平移穿过井口。
- **可游玩的环形外部迷宫**：西南入口已调整为更利于等距相机展示的东南入口；外围三道石门与三枚方向符印依次解锁，路径从入口通向唯一的井口衔接点。

### 技术

- Vite + JavaScript + Three.js
- `OrthographicCamera`（固定斜俯视），实时 WebGL 三维结构与投影
- `ExtrudeGeometry` 石阶 / 环形台面、`CylinderGeometry` 漏斗井壁、程序拼砌的拱券与面孔
- 低分辨率画布配合 `image-rendering: pixelated`，不是 CSS 平面等距贴图
- WASD / 方向键、点击自动寻路、手机触控、符印旋转、音效、通关与重新开始

### 启动

需要 Node.js 20.19+ 或 Node.js 22.12+：

```bash
npm install
npm run dev
npm test
npm run build
```

使用 `npm run dev` 启动本地网页后，打开终端提示的网址。生产版本可以通过仓库的 `.github/workflows/deploy.yml` 发布到 GitHub Pages。Vite 已使用相对路径 `base: './'`，适配项目子路径。

**玩法：** 点击砖块自动寻路，或用 WASD / 方向键移动；靠近三枚符印分别旋转到提示方向，打开三道石门；最后沿井壁螺旋阶梯下到深井底部。移动端有方向键和交互键。

### 项目结构

```text
src/
├── architecture.js    # 石井 / 拱门尺寸、螺旋楼梯轨迹（纯数据，可测试）
├── maze.js            # 圆形迷宫生成、井口唯一入口、机关和寻路
├── scene.js           # 真正的 Three.js 建模与像素化渲染
├── main.js            # 玩家、曲线行走、交互与 UI
├── audio.js           # 程序音效
└── style.css          # 白底 UI、移动端操作

tests/
├── architecture.test.js
└── maze.test.js
```

### 符印特写解谜（交互升级）

靠近符印后按 `E`、点击石台或点「观察符印」，会打开独立的 Three.js 3D 物品特写。鼠标/手机手指左右拖动，或使用 `←`、`→`、左右按钮，以 90° 为单位顺滑吸附旋转。界面显示当前方向、目标方向；方向吻合会有亮光与音效，随后自动返回迷宫，对应石门按原规则下沉。`Esc` / `E` 或退出按钮可随时返回，未解开的当前朝向会原样保留。三枚符印共用同一套特写控制器，按颜色、几何雕饰与原目标方向区分。

新模块：`src/rune-inspector.js` 负责纯表现和输入，`src/rune-turn.js` 在**不修改 `maze.js`** 的前提下复用原 `turnRune()` 的开锁规则；测试在 `tests/rune-turn.test.js`。
